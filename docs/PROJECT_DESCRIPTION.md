## Short Description

**VibeWave** is a mobile musical instrument for smartphones that offers a creative, modern interpretation of the classical theremin controlled by phone movements in 3D space.

The application utilizes built-in motion sensors (gyroscope and accelerometer) to modulate sound in real time. The user can shape the synthesizer's timbre using touch and gestures. The generated audio is enriched with real-time spatial effects such as reverb and modulation filters. Everything is packaged in a minimalist user interface featuring motion-reactive graphic visualization and a musical scale system that enables intuitive melody creation without playing out of tune.

---

## Key Functionalities

- **Basic Waveform Synthesizer:** Real-time tone generation for fundamental waves (sine, square, triangle, sawtooth).
- **Instrument Synthesizer:** Multi-timbral sound presets for acoustic instruments (strings, brass, etc.).
- **Audio Effects:** Real-time spatial and time-based effects including reverb and echo.
- **Musical Scales:** Scale selection and note quantization engine to easily play in key without hitting false notes.
- **Graphic Sound Visualization & UI:** Minimalist interface featuring a dynamic graphical visualization responding to motion and generated sound.

---

## Optional Functionalities

- **Modulation Filters:** Dynamic audio filters such as low-pass filter (LPF) and an equalizer.
- **Customizable Motion Mapping:** Ability to customize sensor axis assignments to audio parameters.
